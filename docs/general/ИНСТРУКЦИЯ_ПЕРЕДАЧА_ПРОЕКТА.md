# Инструкция: как передать проект (ZIP или GitHub)

**Коротко:**
- Папка проекта: `C:\Users\Naiman\IdeaProjects\demo2`
- Для отправки **ZIP**: оставь `src/`, `gradlew*`, `gradle/wrapper/*`, `build.gradle`, `settings.gradle`; удали `build/` и `.gradle/`
- Для отправки через **GitHub**: лучше всего делать `git clone` (и не пушить кэш/сборки)

---

## 1) Где находится проект
Путь в твоём случае:

- `C:\Users\Naiman\IdeaProjects\demo2`

**Проверка в PowerShell:**

```powershell
cd C:\Users\Naiman\IdeaProjects\demo2
pwd
```

**Проверка в IntelliJ IDEA:**
- ПКМ по корню проекта → **Open In → Explorer**
- или **File → Project Structure → Project** → Project location

---

## 2) Как отправить проект ZIP-архивом (без лишних файлов)
### Что НЕ нужно включать (мусор/кэш)
Не отправляй (или удали перед архивированием):
- `build/`
- `.gradle/`
- `.idea/`
- `out/`
- `*.iml`

### Что обязательно должно быть в архиве
Это нужно, чтобы проект **точно** собрался у другого:
- `src/`
- `gradlew`, `gradlew.bat`
- `gradle/wrapper/gradle-wrapper.jar`
- `gradle/wrapper/gradle-wrapper.properties`
- `build.gradle`
- `settings.gradle`
- `README.md` (желательно)

### Как создать ZIP через Проводник
1. Открой папку `C:\Users\Naiman\IdeaProjects\`
2. ПКМ по `demo2` → **Отправить → Сжатая ZIP-папка**
3. Если архив получается слишком большой — удали `build/` и `.gradle/` и повтори

---

## 3) Как отправить проект через GitHub (лучший вариант)
Если проект на GitHub, друг просто сделает `git clone` — это самый правильный способ передачи без мусора.

> Важно: **никогда не публикуй токены** (PAT) в чат/README/код. Если токен засветился — его нужно отозвать и создать новый.

---

## 4) Что должен сделать другой человек после получения
### Если получил ZIP (или папку)

```powershell
cd путь_к_папке_проекта
.\gradlew.bat clean build
.\gradlew.bat bootRun
```

После старта открыть:
- `http://localhost:8080`

---

## 5) Частые проблемы
### Архив огромный
Почти всегда причина — папка `build/` или `.gradle/`. Их не нужно отправлять.

### Не собирается без Gradle
Убедись, что в проекте есть **Gradle Wrapper**:
- `gradlew`
- `gradlew.bat`
- `gradle/wrapper/*`

Если их нет — проект другому будет сложнее запускать.
