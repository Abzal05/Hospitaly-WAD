Лабораторная №10
Стратегия: console
SMTP активен: Нет 
// EmailService — шаг 3 лаб.10
@Service
public class EmailService {
  @Autowired
  JavaMailSender mailSender;

  @Async
  public void sendEmail(
      String to,
      String subject,
      String text) {
    SimpleMailMessage m =
      new SimpleMailMessage();
    m.setTo(to);
    m.setSubject(subject);
    m.setText(text);
    mailSender.send(m);
  }
}
JavaMailSender @Async SMTP / Gmail Strategy Pattern
POST /email/send отправить письмо (Admin)
Включить: app.mail.enabled=true + app.notification.strategy=email в application.properties

✅ Bean Validation — полная цепочка
Валидация на трёх уровнях: аннотации на DTO → @Valid в контроллере → inline-ошибки в форме (MVC) или JSON 400 (REST). 
// ШАГ 1 — аннотации на DTO
@Data
public class LoginRequest {
  @NotBlank(message = "Логин обязателен")
  private String username;

  @NotBlank(message = "Пароль обязателен")
  private String password;
}

@Data
public class UserEditDto {
  @NotBlank(message = "Логин обязателен")
  @Size(min = 3, max = 50, message = "от 3 до 50 символов")
  private String username;

  @Email(message = "Некорректный email")
  private String email;

  @Size(min = 4, message = "минимум 4 символа")
  private String password;
}

// ШАГ 2 — @Valid в MVC-контроллере
@PostMapping("/users/create")
public String create(
    @Valid @ModelAttribute("userDto") UserEditDto dto,
    BindingResult result, Model model) {

  if (result.hasErrors()) {
    model.addAttribute("allRoles", roleRepo.findAll());
    return "admin/user-create"; // форма + ошибки
  }
  userService.create(dto);
  return "redirect:/admin/users";
}
